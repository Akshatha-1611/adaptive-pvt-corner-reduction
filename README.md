# Adaptive PVT Corner Reduction

This project aims to reduce the number of PVT corners required for Static Timing Analysis (STA) using a Python-based adaptive framework.

## Features
- STA automation
- Timing report parsing
- Corner correlation analysis
- Adaptive corner selection
